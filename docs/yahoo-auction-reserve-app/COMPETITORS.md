## 2. 最大手: オークファン「入札予約」の仕組み

設計上いちばん参考になる競合。判明している仕様:

- **サーバー実行型**。「電源OFFでも自動入札」を明確に訴求しており、予約後はユーザー環境に依存しない。本設計のWorker常駐方式と同じ方向。
- **認証はYahoo! JAPAN ID連携(同意フロー)**。ユーザーはブラウザでYahoo! JAPANにログインした状態でツールにアクセスし、連携画面でアプリ連携に同意する。パスワードをオークファンに渡さない。入札予約の確定時にはオークファン側のパスワードを入力させる(誤操作防止)。ログイン中のYahoo IDに紐づく直近120日の入札履歴も表示できる。
  - ※ この連携はオークファンがLINEヤフーと提携関係にあるからこそ成立している可能性が高い。一般の第三者が同じ方式(公式OAuth)で入札まで行うことはできない前提で考える。
- **入札実行はオークション終了の「2分前」固定**。秒単位のスナイプではない。
  - 自動延長が発生した場合は終了時刻を再計算し、新しい終了時刻の2分前に再入札する(本設計 §7.2 と同じ再スケジュール型)。
  - 予約の時間設定自体は「終了48時間前〜2分前」の範囲で選択可能。自動延長ありの商品は6分前設定が推奨されている。
- **失敗はエラーコードで通知**: 999(不明なエラー)、991(オークションサイト混雑による失敗)など。頻発する場合は実行時刻を2〜6分より前に広げることを公式が推奨 = **サイト混雑・処理遅延で直前入札が失敗するのは大手でも避けられていない**。
- **料金による回数制限**: 無料会員は月3回まで。月4回以上はライト会員(¥1,100/月)またはプレミアム会員(¥2,200/月)。

## 3. BidMachine の仕組み

- Windows常駐のデスクトップアプリ。**PCを起動しておく必要がある**のが最大の弱点(オークファンとの差別化点として頻繁に言及される)。
- 入札モードが2種類ある:
  - **一括入札**: 設定した上限額を1回で入札(本設計のデフォルトと同じ)。
  - **追跡入札**: 自動延長ありの商品限定。指定時刻に「最高額入札者になれる最低額」で入札し、高値更新されたら上限額まで最低額の入札を繰り返す。**上限額を最後まで晒さない**ことで、相手の自動入札額のつり上げを最小限にする戦略。
- 商品一覧に自動延長の有無を[延]/[×]で表示。オークションアラート(新着通知)、グループ管理機能あり。
- 料金は**チケット制(従量課金)**。月数回のライトユーザーには月額制より安い。

## 4. ビッドシーン(BidScene)

- 2025年時点の比較記事で「総合力で推奨」とされる後発ツール。
- 特徴は**条件付き入札(グループ入札)**: 複数商品を束ね「どれか1つ落札したら残りは入札しない」という制御。同一商品を安く仕留めたい仕入れユーザー向け。
  - 本設計のフェーズ2「グループ予約」と同一の機能であり、需要の裏付けになる。

## 5. 設計への示唆(DESIGN.md への反映事項)

| # | 示唆 | 反映 |
|---|---|---|
| S-1 | サーバー実行型(電源OFF可)は最大手と同じ土俵であり必須。デスクトップ型(BidMachine)の弱点がそのまま当方の訴求点になる | 反映済み(§4 Worker常駐) |
| S-2 | 最大手ですら実行は「2分前」固定で、混雑起因の失敗(エラー991)を公式に認めている。**「秒単位スナイプ(デフォルト10秒前)」はそのまま差別化ポイントになるが、混雑・遅延リスクも同時に負う**。デフォルトをやや安全側(30秒前)にし、5〜300秒で選択可+失敗率の実測を P0 検証に含める | DESIGN.md §7.1 を更新 |
| S-3 | 自動延長時の「終了時刻再計算→再入札」はオークファンも同じ。ここは同等でよい | 反映済み(§7.2) |
| S-4 | BidMachineの**追跡入札**(上限額を晒さず最低額で刻む)は自動延長あり商品で有効な差別化機能。フェーズ2に追加 | DESIGN.md §3.2 に追加 |
| S-5 | グループ予約(条件付き入札)はBidSceneの主力機能=需要あり。フェーズ2の優先度を上げる | §3.2 記載済み |
| S-6 | 認証面: オークファンのYahoo ID連携(公式同意フロー)は提携前提で真似できない。当方のCookie預かり方式は**「パスワードは預からない・暗号化保管・いつでも削除可」を明示して、フィッシング系無料ツールとの信頼性の差**を訴求する | §8 の方針を維持、LPでの訴求に追加 |
| S-7 | 価格ベンチマーク: 無料 月3回 / 無制限 ¥1,100〜2,200/月(オークファン)、従量チケット制(BidMachine)。フリーミアム(無料 月3〜5回+月額 ¥980〜1,500 目安)+将来チケット制の余地 | 事業判断。設計への影響なし |
| S-8 | オークファンは連携中のYahoo IDの入札履歴(120日)表示や、予約確定時の自サービス側パスワード再入力(誤発注防止)などUX工夫がある。確定時の確認ステップは取り入れる | 予約登録フローに確認ステップを追加(§10) |
